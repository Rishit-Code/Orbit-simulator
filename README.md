# Orbit-Simulator

An interactive web-based application designed to simulate Hohmann Transfer maneuvers and visualize orbital mechanics in real-time. 

## 🚀 Features

* **Hohmann Transfer Calculator:** Computes precise $\Delta v$ requirements for transitioning between two coplanar circular orbits.
* **Real-time ISS Tracking:** Fetches live telemetry data from the International Space Station using the Skyfield library.
* **Interactive Dashboard:** Built with Streamlit to provide a user-friendly interface for physics simulation and data visualization.

## 🛠 Tech Stack

* **Language:** Python
* **Web Framework:** Streamlit
* **Libraries:**
    * Skyfield (for high-precision astronomical data)
    * NumPy (for orbital calculations)
    * Matplotlib (for trajectory visualization)
